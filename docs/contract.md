# Finish-to-start critical path v1

为项目计划分析者核一份任务依赖快照，生成最早/最晚起止、总时差/自由时差与关键路径证据。
tasks为1..1000项，每项唯一id、duration=0..10^6整数时间单位、唯一predecessors列表；
引用完整且依赖图无环。0耗时里程碑合法，负耗时/自环/循环失败，不按输入顺序调度。

假定无限资源、无日历、所有任务时刻0可开始、finish-to-start零时滞；项目终点为所有任务最早结束的最大值。
正向ES=max父EF，EF=ES+duration；反向LF=min子LS（无子任务取项目终点），LS=LF-duration。
总时差=LS-ES，自由时差=min子ES-EF（终点取项目终点）。关键活动总时差0；关键边还需父EF=子ES。
输出全部活动与关键边，选择字典序确定的一条关键路径，不声称枚举所有关键路径。

样例工期8，A→C→D关键；B总时差2，自由时差2，独立E总时差6。
不把关键路径分析等同资源可行计划或完成日期预测。当前无资源平衡、概率工期、成本压缩、
实际进度、日期日历或持久计划系统；与物料需求展开的供给净算不是同一业务。
